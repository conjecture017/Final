PSGX Global Landing PageThis is a lightweight, high-performance, single-page application built using React, Tailwind CSS, and FontAwesome. It requires no complex build steps or Node.js environment.Deployment Instructions (Vercel)Deploying this site is incredibly straightforward:Create a folder on your computer (e.g., psgx-global-website).Download the source files from your editor and place them in the folder:index.htmlvercel.jsonDeploy via Vercel:Option A (Vercel CLI): Open your terminal in the folder and run vercel.Option B (Vercel Dashboard): Drag and drop your folder directly into the Vercel Dashboard, or push the folder to a GitHub repository and import it into Vercel.FeaturesZero Build Step: React and Tailwind load instantly via CDN.Conversion Tracking: Meta Pixel is pre-configured for PageViews and Lead events.Responsive Design: Fully mobile-optimized layouts and menus.Direct Contact Links: Configured Mailto links and a floating WhatsApp widget.
